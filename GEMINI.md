# Antigravity Rules for AmarDNS

## ⛔ Permanent Constraint: No Fly.io Deployment
- **NEVER** run `fly`, `flyctl`, or any Fly.io deployment tools.
- **NEVER** push or deploy this project to Fly.io.
- Fly.io deployment has been permanently retired and disabled.
- The project is deployed exclusively via Docker containers and GitHub Actions releases.
